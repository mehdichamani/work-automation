# 📁 ساختار پروژه (Project Structure)

این سند ساختار دایرکتوری‌ها، فایل‌ها و اجزای مختلف پروژه **سامانه اتوماسیون اداری اروم شیشه ساچی** را تشریح می‌کند. پروژه دارای معماری Full-Stack با دو بخش کاملاً مجزای بک‌اند (Node.js/Express) و فرانت‌اند (React/Vite) است.

---

## 📂 ساختار کلی ریشه پروژه (Root)

```text
.
├── .agents/                    # قوانین و دستورالعمل‌های مخصوص هوش مصنوعی و عوامل توسعه‌دهنده
│   └── AGENTS.md               # قوانین کامیت‌ها و راهنماها
├── backend/                    # بخش سرور و منطق تجاری (Express.js)
├── docs/                       # مستندات تکمیلی سیستم (فایل‌های مارک‌دان حاضر)
├── docker/                     # پیکربندی‌های مربوط به کانتینرسازی (در صورت استفاده)
├── frontend/                   # بخش کلاینت و رابط کاربری (React + Vite)
├── .env.example                # نمونه فایل متغیرهای محیطی
├── .gitignore                  # فایل‌های نادیده‌گرفته‌شده توسط گیت
├── auto-start.vbs              # اسکریپت اجرای خودکار در پس‌زمینه ویندوز
├── DOCS.md                     # سند مرجع اصلی راهنما (فهرست مستندات)
├── ecosystem.config.js         # پیکربندی PM2 جهت مدیریت فرآیندها
├── manage.bat                  # اسکریپت کمکی منوی مدیریتی تحت ویندوز (Batch)
├── manage.ps1                  # اسکریپت پشت‌صحنه PowerShell برای مدیریت پروژه
└── README.md                   # راهنمای کلی و سریع راه‌اندازی پروژه
```

---

## 🔙 بخش بک‌اند (`backend/`)

بخش بک‌اند مسئولیت مدیریت نشست‌ها، احراز هویت، ارتباط با پایگاه داده PostgreSQL، مدیریت کارتابل اداری و فرآیندهای کسب‌وکار را بر عهده دارد.

```text
backend/
├── backup/                     # محل ذخیره‌سازی فایل‌های پشتیبان پایگاه داده (.sql و zip)
├── database/                   # مدیریت پایگاه داده
│   ├── config.js               # تنظیمات اتصال به PostgreSQL با استفاده از pg.Pool
│   ├── init.js                 # تعریف جدول‌ها، نقش‌ها، سطوح دسترسی و روابط دیتابیس
│   ├── init_local_db.js        # اسکریپت راه‌اندازی و مقداردهی دیتابیس محلی
│   └── reset_local_db.js       # اسکریپت بازنشانی کامل پایگاه داده محلی (حذف و ساخت مجدد)
├── middleware/                 # میان‌افزارهای امنیتی و اعتبارسنجی
│   # شامل کنترل دسترسی، احراز هویت JWT، لاگ فعالیت‌ها و کنترل محدودیت نرخ درخواست (Rate Limit)
├── routes/                     # کنترل‌کننده‌ها و مسیرهای API (تفکیک‌شده بر اساس قابلیت‌ها)
│   ├── auth.js                 # احراز هویت، ثبت نام، ورود و خروج کاربران
│   ├── smsAuth.js              # تأیید هویت دو مرحله‌ای پیامکی (SMS OTP)
│   ├── leave.js                # مدیریت درخواست‌های مرخصی روزانه/ساعتی
│   ├── letters.js              # کارتابل نامه‌ها (ثبت، ارجاع، امضا و بایگانی)
│   ├── workflow.js             # تعریف و پیگیری چرخه‌های کاری و فرآیندهای اداری
│   └── ... (سایر مسیرها برای بقیه ماژول‌ها)
├── tests/                      # تست‌های واحد و یکپارچه‌سازی (نوشته شده با Jest و Supertest)
├── utils/                      # توابع کمکی (امنیت، زمان، پیامک، ایمیل، سوکت و غیره)
├── package.json                # وابستگی‌ها و اسکریپت‌های اجرایی بک‌اند
└── server.js                   # نقطه ورود اصلی برنامه بک‌اند (تنظیم Express، Socket.io و پورت‌ها)
```

## 💻 بخش فرانت‌اند (`frontend/`)

فرانت‌اند با فریم‌ورک مدرن React و ابزار Vite برای بیلد سریع توسعه یافته است. استایل‌دهی با **Tailwind CSS** انجام شده است.

```text
frontend/
├── public/                     # فایل‌های استاتیک عمومی (مانند لوگو، آیکون‌ها و تصویرسازها)
├── src/                        # کدهای منبع اصلی برنامه
│   ├── api/                    # پیکربندی اتصال به API (کلاینت Axios، توابع آماده ارسال درخواست)
│   ├── components/             # کامپوننت‌های بازاستفاده‌پذیر (دکمه‌ها، جدول‌ها، مدال‌ها، منوها)
│   ├── context/                # مدیریت وضعیت سراسری (Context API مانند احراز هویت، تم و غیره)
│   ├── pages/                  # صفحات اصلی برنامه (داشبورد، کارتابل، بخش پرسنلی، چت، تنظیمات)
│   ├── utils/                  # توابع کمکی فرانت‌اند (مانند تبدیل تاریخ شمسی، فرمت‌دهی پول و غیره)
│   ├── App.jsx                 # کامپوننت ریشه و تنظیم مسیریابی (Routing) با React Router
│   ├── index.css               # استایل‌های سراسری و پیکربندی اولیه Tailwind CSS
│   └── main.jsx                # نقطه ورود رندر React به DOM مرورگر
├── package.json                # وابستگی‌ها و اسکریپت‌های بیلد کلاینت
├── tailwind.config.js          # تنظیمات کاستومایز کردن Tailwind CSS
└── vite.config.js              # پیکربندی ابزار ساخت و توسعه Vite
```
