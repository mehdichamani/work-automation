# 🏢 سامانه اتوماسیون اداری اروم شیشه ساچی

این پروژه یک سیستم جامع اتوماسیون اداری و مدیریت فرآیندهای سازمانی برای **شرکت اروم شیشه ساچی** است. این سامانه با معماری مدرن و دوپشته‌ای (Full-Stack) با استفاده از **React/Vite** در سمت کلاینت و **Express/Node.js** در سمت سرور توسعه یافته و برای مدیریت بهینه کارهای اداری، هماهنگی تیم‌ها و اتوماتیک‌سازی فرآیندهای اداری طراحی شده است.

---

## ✨ قابلیت‌های کلیدی سامانه

سامانه شامل بخش‌ها و ویژگی‌های کلیدی زیر است:

*   **👥 مدیریت کاربران و سطوح دسترسی (HR & Auth):** ثبت نام، ورود دو مرحله‌ای پیامکی (SMS OTP)، امضای دیجیتال پرسنل و کنترل سطوح دسترسی پویا.
*   **📑 مکاتبات و گردش کار (Workflows & Letters):** سیستم ثبت، ویرایش، امضا و ارجاع نامه‌های اداری و درخواست‌ها با قابلیت پیگیری مراحل گردش کار (کارتابل اداری).
*   **⏱️ خدمات رفاهی و پرسنلی (Staff Services):** ثبت و مدیریت درخواست‌های مرخصی، مأموریت، اضافه کاری، مساعده حقوق و رزرو غذای رستوران شرکت.
*   **📊 عملیات و گزارش‌های فنی (Operations):** ثبت گزارش کارهای روزانه، حجم تولید روزانه (Daily Output)، درخواست‌های پشتیبانی IT، تعمیرات تجهیزات و درخواست سفارش خرید کالا.
*   **💬 ابزارهای ارتباطی و هماهنگی (Communication):** چت و گفتگو درون‌برنامه‌ای، سیستم اعلانات و نوتیفیکیشن‌های آنی (Socket.io)، رزرو اتاق کنفرانس و تابلوی اعلانات شرکت.
*   **⚙️ ابزارهای سیستم و امنیت (System & Security):** تهیه فایل پشتیبان (Backup) دستی و خودکار از دیتابیس، لاگ ممیزی (Audit Log) فعالیت‌ها و امنیت بالا با استفاده از Helmet و Rate Limiting.

## 🛠️ پیش‌نیازها و راه‌اندازی سریع (مخصوص ویندوز)

برای راحتی اجرای پروژه در سیستم‌عامل ویندوز، ابزارهای کمکی آماده شده است.

### ۱. تنظیم فایل تنظیمات محیطی (`.env`)
ابتدا فایل `.env.example` موجود در ریشه پروژه را کپی کرده و نام آن را به `.env` تغییر دهید. سپس اطلاعات دیتابیس PostgreSQL خود و پورت سرور را در آن وارد نمایید.

### ۲. استفاده از ابزار مدیریت هوشمند (`manage.bat`)
یک ابزار خط فرمانی بسیار آسان به نام `manage.bat` (فایل کمکی PowerShell) در پوشه اصلی قرار دارد که تمامی مراحل را به صورت خودکار انجام می‌دهد:

1. فایل **`manage.bat`** را اجرا کنید.
2. برای نصب تمام پکیج‌های کلاینت و سرور و همچنین بیلد گرفتن فرانت‌اند، گزینه **`5`** (Install Application) را انتخاب کنید.
3. جهت ساخت و راه‌اندازی اولیه پایگاه داده، گزینه **`1`** (Initialize/Create Local Database) را بزنید.
4. برای استارت سامانه در بستر PM2 و باز شدن خودکار مرورگر، گزینه **`6`** (Start Application) را انتخاب کنید.

## 💻 راهنمای نصب و راه‌اندازی دستی

در صورتی که می‌خواهید پروژه را به صورت دستی روی هر سیستم‌عاملی راه‌اندازی کنید، مراحل زیر را دنبال نمایید:

### بخش سرور (Backend)
1. وارد پوشه `backend` شوید:
   ```bash
   cd backend
   ```
2. وابستگی‌ها را نصب کنید:
   ```bash
   npm install
   ```
3. پایگاه داده را مقداردهی اولیه کنید (مطمئن شوید PostgreSQL در حال اجراست و تنظیمات `.env` درست است):
   ```bash
   node database/init_local_db.js
   ```
4. سرور را اجرا کنید:
   ```bash
   npm start
   ```
   *سرور به طور پیش‌فرض روی پورت `2833` اجرا می‌شود.*

### بخش کلاینت (Frontend)
1. وارد پوشه `frontend` شوید:
   ```bash
   cd ../frontend
   ```
2. وابستگی‌ها را نصب کنید:
   ```bash
   npm install
   ```
3. برنامه را در حالت توسعه (Dev) اجرا کنید یا نسخه نهایی (Build) آن را بسازید:
   ```bash
   # حالت توسعه
   npm run dev

   # ساخت نسخه نهایی جهت سرور کردن توسط بک‌اند
   npm run build
   ```

## 🚀 استقرار و شروع خودکار (Autostart)
این پروژه از **PM2** برای مدیریت فرآیندهای پس‌زمینه استفاده می‌کند. با استفاده از فایل `ecosystem.config.js` فرآیندها مدیریت می‌شوند. همچنین می‌توانید از گزینه‌های **`8`** و **`9`** در منوی ابزار `manage.bat` برای فعال‌سازی یا غیرفعال‌سازی اجرای خودکار برنامه هم‌زمان با روشن شدن ویندوز استفاده کنید.
